# 📊 Customer Churn & Retention Analysis Dashboard

## 🔍 Project Overview

This project analyzes customer churn behavior using the Telco Customer Churn dataset. The goal is to identify key factors driving customer attrition and provide actionable insights to improve retention.

## 🎯 Objectives

* Analyze churn patterns and trends
* Identify high-risk customer segments
* Perform retention and cohort analysis
* Generate business recommendations

## 🛠 Tools & Technologies

* Power BI
* Excel
* Data Visualization
* DAX (Data Analysis Expressions)

## 📈 Key Features

* KPI Cards: Total Customers, Churn Rate, Revenue, Avg Tenure
* Churn Analysis by Contract, Payment Method, Services
* Customer Lifetime & Tenure-based insights
* Interactive filters (slicers)

## 💡 Key Insights

* Month-to-month contracts show higher churn
* Customers with low tenure are more likely to churn
* Electronic check users have higher churn rates
* Lack of tech support increases churn probability

## 🚀 Business Recommendations

* Encourage long-term contracts with discounts
* Improve onboarding for new customers
* Promote automatic payment methods
* Provide better customer support services

## 📂 Dataset

* Source: Kaggle (Telco Customer Churn Dataset)
